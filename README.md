# Girlfriend's Day Sunflower

A small interactive Girlfriend's Day greeting built with React, Vite, GSAP, Framer Motion, and canvas-confetti.

## Development

```powershell
npm install
npm run dev
```

## Production build

```powershell
npm run lint
npm run build
npm run preview
```

## Updating the note

Edit `src/content/message.js`. The animation and layout do not need to change when the final note is added.

## Deployment

The site is configured for Vercel's Vite preset:

- Build command: `npm run build`
- Output directory: `dist`
